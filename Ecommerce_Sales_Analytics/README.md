# E-Commerce Sales Analytics Dashboard

## About the Project
An interactive dashboard built using Python, Pandas, and Streamlit to analyze e-commerce sales data and understand business performance.

## Features
- Key performance indicators: Total Revenue, Total Orders, Total Customers, and Average Rating.
- Interactive filters by region and product category.
- Revenue analysis by product category and region.
- Monthly revenue trend visualization.
- Orders by payment method.
- Quantity sold by product category.
- Average delivery days by region.
- Top 5 orders by revenue.
- Business insights and CSV data download.

## Technologies Used
- Python
- Pandas
- Streamlit

## Dataset
The project uses an e-commerce sales dataset containing 5,000 records.

## How to Run the Project
1. Download or clone this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the dashboard:

   `streamlit run app.py`

4. Open the local URL displayed in the terminal.

## Project Goal
To explore e-commerce sales data, visualize business performance, and make it easier to identify useful sales insights.
